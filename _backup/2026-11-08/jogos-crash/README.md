# Lucky Charm Demo (educativo)

Crash (estilo avião), laboratório de integridade e slot, com **créditos fictícios** (sem dinheiro real, sem pagamentos).

```
node server.js     # http://localhost:3000   (sem npm install)
node --test        # 35 testes
```

Páginas: `/` Crash · `/lab.html` Laboratório · `/slot.html` Slot.
Documentação para o TCC (arquitetura, falhas × proteções, experimentos, como testar): **DOC-TCC.md**.
Apoio sobre jogo problemático: CVV 188.
