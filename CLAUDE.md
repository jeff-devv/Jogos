# Lucky Charm

Siga **PADRAO.md** em toda alteração (estrutura, JS, PHP, dinheiro em centavos, como adicionar jogo).

- Backend Node existe só na raiz (`server.js`, `lib/`, `lab/`, `game.js`). Não criar cópias em `public/`.
- `_backup/` é arquivo morto: não editar nem referenciar.
- Depois de mudar código Node: `npm test` (35 testes). Depois de mudar PHP: `C:\xampp\php\php.exe -l <arquivo>`.
- Respostas e textos de tela em português.
